# Reader

Reader is a professional teleprompter app for content creators, journalists, public speakers and students.

**App Related Info**

Floating overlay teleprompter that stays on top of Camera, TikTok, YouTube, Instagram and any recording app. You can move it, resize it, change opacity and control scrolling speed from 0.5x to 10x with smooth 60fps scroll. No need to memorize scripts.

Text to speech studio converts any script into natural audio. You can change pitch and speed, auto detects English, Arabic, Urdu, Hindi, Spanish, French, German, Chinese, Russian and more. Audio saves locally for offline practice.

Smart script management to create, edit and organize unlimited scripts. Editor shows word count and character count with auto save. Search by title or content. All scripts are stored locally on device only, 100 percent private, no cloud, no login.

Share and export with Android native share sheet. Share via WhatsApp, Telegram, Email and any app. Copy to clipboard in one tap, save as txt file, print with watermark.

Speed and display control with real time slider, text size control, high contrast design with 3 colors teal #009688, white #FFFFFF, dark #202124 for eye comfort.

Lightweight under 15mb, works offline, works on Android 7.0 and above.

**Future Related Info**

Upcoming updates for Reader include ai script improver to make scripts more engaging, voice cloning to read scripts in your own voice, optional cloud sync to backup scripts across devices, collaboration mode to share scripts with team, auto captions generator from recordings, bluetooth remote control for hands free scrolling, home screen widget for recent scripts, dark mode and custom themes, import from pdf and docx files, and folder organization for scripts.
